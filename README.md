# PDF OCR & Document Extraction Pipeline

An end-to-end document processing pipeline built using Python, Docling, PyMuPDF, OpenCV, and EasyOCR.

## Features

- PDF to Image Conversion
- OCR Text Extraction
- Table Extraction
- Markdown Generation
- JSON Export
- Structured Document Processing

## Tech Stack

- Python
- Docling
- PyMuPDF
- EasyOCR
- OpenCV
- Pandas

## Output

- Markdown (.md)
- JSON (.json)
